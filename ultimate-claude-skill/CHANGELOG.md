# Changelog

## 1.0.0 (2026-09-27)

First release.

- Core loop: understand, classify (spike, bounded, architectural), plan with checks, build small, verify
- Four iron laws: failing test first, root cause before fix, evidence before claims, approval before implementation
- Red-flag table covering planning, coding, debugging, verification, security, design, writing, and research
- Reference guides: process, coding and TDD, debugging, verification and review, security, design, writing, research, output modes, skill authoring
- Templates: task plan, findings, progress, spec, implementation plan, debug log, code review checklist, design brief
- `ultikit.py` with three commands: `slop` (prose checker with 50-point score), `design` (generated-default and quality-floor checker), `plan` (planning-file scaffolder)
- Sources from 14 of the most-starred Claude skill repos, listed in `SOURCES.md`
- Claude Code plugin and marketplace manifests
- Combined documentation in `docs/` (Markdown, HTML, PDF) and `tools/build_docs.py` to rebuild it
- `CLAUDE.md` with contributor instructions for Claude Code
